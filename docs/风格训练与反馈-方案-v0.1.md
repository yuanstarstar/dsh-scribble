# DSH 手稿 · 风格训练与反馈闭环方案

- **版本**：v0.1（增补方案，待验收）
- **日期**：2026-11-12
- **依赖**：[主方案 v0.2](方案-v0.1.md) 的 M1（笔画引擎、历史记录、`scribble_write` / `scribble_draw`）
- **一句话**：不训练大模型；把“训练”做成**低维风格画像 + 偏好学习 + 可选的逐字变形**。这样 1 张旧画就能“捕获风格”，10 来次反馈就能“学会偏好”，需要真正字形时再让用户写一张 A–Z 样张。

---

## 0. 先分清两件事：风格 ≠ 字形

| | 风格（Style） | 字形（Glyph shape） |
|---|---|---|
| 是什么 | 倾斜、粗细、对比、圆角、抖动、字距、基线、收笔、墨水质感 | 每个字母/汉字的具体骨架和比例 |
| 从哪来 | 旧画、旧字、滑杆、A/B 反馈 | 用户逐字写的样张、手写照片、描摹 |
| 数据量 | 1 张画就能估一个大概；10–20 次反馈稳定 | 拉丁至少 26+26+10 个样本；中文要几千字 |
| 本方案 | **S1/S2 必做** | **S3 可选，只做拉丁** |

“训练出自己的风格的字体”可以落在三个层级：

1. **L0 风格捕获**：把之前画过的某张画/某段字的风格参数提取出来，套到新文字上。零训练、即时可用。
2. **L1 偏好学习**：用户对生成结果点“像/不像”、A/B 选一张、说“太工整/太潦草”；系统更新风格画像。这是本方案的主菜。
3. **L2 字形适配**：用户写一张 A–Z/0–9 样张（或上传手写照片），系统分割、矢量化、对齐，学习每个字的变形，导出真正“像自己字”的 TTF。工作量大，放 S3，只承诺拉丁。
4. **L3 神经字体生成**（DG-Font/MXFont 一类）：不做。模型重、非确定、难本地部署，且对“个人风格”并不比 L0–L2 更实用。

> 结论：先把 L0+L1 做成闭环，用户会立刻感觉“它记得我的风格”；L2 作为进阶，不阻塞首版。

## 1. “之前绘画时的风格反馈”指什么

本方案把它拆成三个可执行的动作：

### 1.1 从旧画捕获风格（capture）

插件每次 `scribble_draw` / `scribble_write` 都把**解析后的完整风格向量 + 笔画快照**写进历史，而不是只存 PNG：

```json
{
  "drawingId": "drw_20261112_001",
  "tool": "scribble_draw",
  "template": "stick_figure",
  "style": {
    "slant": 0.04,
    "weight": 0.043,
    "contrast": 0.35,
    "roundness": 0.6,
    "jitter": 1.2,
    "baselineBounce": 0.008,
    "tracking": 0.03,
    "endTaper": 0.4,
    "inkTexture": 0.2
  },
  "seed": 20261112,
  "strokesRef": "history/drw_20261112_001.strokes.json",
  "files": { "png": "...", "svg": "..." }
}
```

于是“用这张画的风格写字”不需要图像识别，直接：

```text
scribble_style { action: "capture", drawingId: "drw_20261112_001", name: "我的手写" }
→ 生成 StyleProfile
scribble_write { text: "HELLO", profile: "prof_xxx" }
```

**跨模态**是天然成立的：火柴人的线宽、抖动、圆角，和字体的线宽、抖动、圆角，用的是同一套 `Style` 字段。

### 1.2 从多张旧画里“取平均”（learn）

用户勾选 3–10 张“像我”的作品，系统做**加权风格聚合**：

```text
μ = Σ w_i θ_i / Σ w_i
Σ = λI + Σ w_i (θ_i - μ)(θ_i - μ)^T / Σ w_i
```

- `θ_i`：第 i 张画的风格向量；
- `w_i = 时间衰减 × 用户评分 × 相似度`；
- `μ`：默认风格；`Σ`：允许的探索范围；
- 生成时从 `N(μ, αΣ)` 采样，`α` 小就是“稳定”，大就是“来点变化”。

这比“让模型看几张图然后自由发挥”可控得多：用户能看到“当前风格”的滑杆和置信度。

### 1.3 用反馈修正（feedback）

三种反馈，信息量从低到高：

| 反馈 | 例子 | 用法 |
|---|---|---|
| 绝对评分 | “这张 5 分 / 2 分” | 调整样本权重，简单但噪声大 |
| 标签 | “太工整”“太斜”“太细” | 映射到具体维度，直接修正 |
| A/B 对比 | “这两张里我更喜欢右边” | 训练偏好模型，信息量最大 |

A/B 用 Bradley–Terry / 逻辑回归：

```text
p = σ( w · (φ(θ_a) - φ(θ_b)) )
w ← w + η (y - p)(φ(θ_a) - φ(θ_b)) - λw
```

- `y=1` 表示更喜欢 a；
- `φ(θ)` 是风格特征（可加交互项）；
- `w` 只有十几维，几十次对比就能收敛，纯 JS 毫秒级；
- 生成时采样 K 个候选，用 `w·φ(θ) - β||θ-μ||²` 打分，选最好的；保留 ε 探索，避免风格塌缩。

**对话内反馈**：用户说“这张不错”“太潦草了”，模型调用 `scribble_feedback` 记录；不需要先做 UI。

## 2. 闭环架构

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 生成                                                    │
│    scribble_write / scribble_draw                          │
│    → 解析 style + seed + strokes                           │
│    → 输出 PNG/SVG + drawingId                              │
└──────────────────────────┬──────────────────────────────────┘
                           │ 自动写历史
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 记录                                                    │
│    history.jsonl：drawingId / style / seed / strokesRef    │
│    feedback.jsonl：rating / tags / A-B / note              │
└──────────────────────────┬──────────────────────────────────┘
                           │ capture / learn
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 风格画像                                                │
│    StyleProfile：μ / Σ / confidence / glyphDeviations      │
│    preference：w / bias                                    │
└──────────────────────────┬──────────────────────────────────┘
                           │ 采样 / 打分 / 应用
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 再生成                                                  │
│    scribble_write { profile } → 新图 → 新反馈 → 更新画像   │
└─────────────────────────────────────────────────────────────┘
```

**冷启动**：

- 没有 profile → 用内置预设；
- 第一张图生成后，用户说“就这个风格” → `capture`；
- 有 1 张 → 低置信度捕获；
- 有 5–10 张/反馈 → 稳定；
- 有 20+ → 可以关掉探索，固定成“我的字体”。

## 3. 数据格式

### 3.1 `StyleProfile`

```json
{
  "schema": 1,
  "id": "prof_01",
  "name": "我的手写",
  "basePreset": "child",
  "createdAt": "2026-11-12T23:30:00+08:00",
  "updatedAt": "2026-11-12T23:45:00+08:00",
  "style": {
    "slant": 0.052,
    "weight": 0.043,
    "contrast": 0.38,
    "roundness": 0.62,
    "jitter": 1.15,
    "baselineBounce": 0.008,
    "tracking": 0.032,
    "xHeight": 0.52,
    "capHeight": 0.72,
    "ascender": 0.78,
    "descender": 0.22,
    "endTaper": 0.42,
    "inkTexture": 0.22
  },
  "confidence": {
    "slant": 0.82,
    "weight": 0.76,
    "jitter": 0.64,
    "tracking": 0.55
  },
  "stats": {
    "drawings": 12,
    "feedback": 18,
    "comparisons": 9
  },
  "glyphDeviations": {},
  "preference": {
    "weights": { "slant": 0.3, "jitter": -0.2, "weight": 0.1 },
    "bias": 0.0
  }
}
```

- `style` 是归一化后的数值；渲染时再映射到具体像素；
- `confidence` 每维 0–1，UI 用进度条显示“还不太确定”；
- `glyphDeviations` 只有 L2 才有；
- `preference.weights` 只有经过 A/B 才有。

### 3.2 历史与反馈

`history.jsonl`（追加写，按行）：

```json
{"drawingId":"drw_001","tool":"scribble_write","text":"DSH","style":{...},"seed":42,"strokesRef":"history/drw_001.strokes.json","files":{"png":"...","svg":"..."},"createdAt":"..."}
```

`feedback.jsonl`：

```json
{"drawingId":"drw_001","rating":1,"tags":["too_tidy"],"note":"太工整了","createdAt":"..."}
{"drawingId":"drw_003","compareTo":"drw_004","preferred":"other","createdAt":"..."}
```

- 历史默认保留最近 200 条 + 用户“收藏”的条目；
- 笔画快照用于精确 capture；只有 PNG 时退化为图像近似（置信度低）；
- 所有文件在 `~/.dsh/scribble/` 下，原子写（临时文件 + rename）。

## 4. 学习算法

### 4.1 L0：风格捕获（S1）

- 输入：一个或多个 `drawingId`；
- 若历史里有完整 `style`：直接取加权平均，置信度 = 样本数函数；
- 若只有 PNG：近似提取（见 §4.5），置信度打七折；
- 输出：`StyleProfile`，`stats.drawings = n`；
- 支持“以这张为主，其他几张只做微调”：主样本权重 1.0，其他 0.2–0.5。

### 4.2 L1：加权画像（S2）

- 维护 `μ`、`Σ`；
- 每次 capture/feedback 后增量更新；
- 时间衰减：半衰期 30 天或 20 张图（可配置）；
- 评分权重：`rating` 映射到 0.5–1.5；
- 相似度：与当前 `μ` 的余弦/欧氏距离，避免离群样本把风格拉跑；
- 正则：`λ=0.05`，小样本时向 `basePreset` 收缩（经验贝叶斯味道）；
- 生成：`θ = μ + α L z`，`α=0.15`（稳定）或 `0.35`（探索）；裁剪到合法范围。

### 4.3 L1.5：偏好学习（S2）

- 特征 `φ(θ)`：13 个风格维度 + 少量交互（如 `slant×weight`）；
- 每次 A/B 更新 `w`；
- 绝对评分也转成“与当前 μ 的对比”弱标签；
- 标签反馈直接改维度：
  - “太工整” → `jitter += 0.1`、`roundness += 0.05`；
  - “太斜” → `slant -= 0.02`；
  - “太细” → `weight += 0.005`；
- 生成候选：K=8，`score = w·φ(θ) - β||θ-μ||²`，取 top-1；10% 概率随机探索；
- 防止过拟合：`w` 的 L2 正则；一次反馈只更新一小步（学习率 0.05）。

### 4.4 L2：逐字变形（S3，可选，仅拉丁）

1. 生成一张**可打印样张**：A–Z、a–z、0–9，每个字一个方框 + 基线/中线；
2. 用户手写后拍照/扫描上传；
3. 预处理：灰度、二值化、去噪、按框分割、骨架化；
4. 对齐：与内置骨架做 Procrustes（平移/缩放/旋转/剪切）；
5. 残差建模：
   ```text
   r(p) = A p + b + Σ_k c_k φ(||p - c_k||)
   ```
   `A` 是全局仿射，`c_k` 是 RBF 系数；用岭回归拟合；
6. 未写的字：只应用全局仿射 + 风格，不应用 RBF；
7. 导出 TTF 时把变形后的骨架转轮廓。

**限制**：

- 手写照片的骨架化质量不稳定；优先用“打印样张 + 框内书写”降低分割难度；
- 中文不做 L2（工作量/许可证/质量问题）；
- 不承诺“一次拍照就完美”，允许用户在 UI 里微调控制点（后续）。

### 4.5 只有图片时怎么近似

从 PNG 提取（置信度低，只用于旧图/外部图）：

- **笔画宽度**：距离变换的中位数 × 2；
- **倾斜**：图像矩 / 主成分方向；
- **基线**：水平投影的峰值；
- **字距**：连通域间距；
- **抖动**：骨架平滑后的高频残差；
- **墨水密度**：前景像素占比。

如果历史里有矢量 `strokes`，优先用矢量，精度高一个量级。**所以 M1 一定要把笔画快照存下来**，这是本方案的关键前置条件。

## 5. 工具接口

### 5.1 `scribble_style`

| action | 参数 | 作用 |
|---|---|---|
| `history` | `limit` | 列出最近作品（id/风格/缩略图/评分） |
| `capture` | `drawingId` 或 `drawingIds`, `name`, `weights?` | 从旧画生成 profile |
| `learn` | `window?`, `dryRun?` | 用历史+反馈重算 μ/Σ/w |
| `list` / `get` | `id?` | 查看 profile |
| `activate` | `id` | 设为默认 |
| `preview` | `id`, `text?` | 用该 profile 出样张 |
| `export` / `import` | `id`, `path` | 导出/导入 JSON |
| `reset` / `delete` | `id` | 重置/删除 |

### 5.2 `scribble_feedback`

```json
{
  "drawingId": "drw_001",
  "rating": 1,
  "tags": ["too_tidy"],
  "compareTo": "drw_002",
  "preferred": "other",
  "note": "右边更像我的手写"
}
```

- `rating`: -1 / 0 / 1，或 1–5；
- `tags`: `too_tidy` / `too_messy` / `too_slanted` / `too_thin` / `too_thick` / `too_round` / `like`;
- `compareTo` + `preferred`: A/B；
- 反馈写入 `feedback.jsonl`，下一次生成自动用新 profile。

### 5.3 对现有工具的改动

- `scribble_write`：新增 `profile`（默认当前激活 profile）；
- `scribble_draw`：新增 `profile`；
- `scribble_font`：`specimen` / `export` 新增 `profile`；
- 返回新增：`profileId`、`confidence` 摘要、`drawingId`（供反馈用）。

### 5.4 对话内闭环示例

```text
用户：写个“DSH”，用我上次那张画的风格。
模型：scribble_style { action:"capture", drawingId:"drw_0912" }
     → prof_01
     scribble_write { text:"DSH", profile:"prof_01" }
     → 图片 + drawingId
用户：这张不错，但有点太工整。
模型：scribble_feedback { drawingId:"drw_1013", rating:1, tags:["too_tidy"] }
     scribble_write { text:"DSH", profile:"prof_01" }  // 自动多一点抖动
```

不需要 UI 也能跑通；UI 只是把同样的动作可视化。

## 6. 存储、隐私与版本

```text
~/.dsh/scribble/
├─ profiles/
│  └─ prof_01.json
├─ history.jsonl
├─ history/
│  └─ drw_001.strokes.json
├─ feedback.jsonl
└─ cache/hanzi/
```

- 全部本地；不上传、不遥测；
- profile 可导出 JSON，用户可备份/迁移；
- `schema` 版本号；升级时做迁移；
- 历史默认 200 条，超出按时间淘汰，收藏的保留；
- 笔画快照可能较大，单条上限 2 MB；超出只存 PNG + 参数；
- 删除 profile 不删除历史；删除历史不删用户导出的文件。

## 7. UI / 交互（S4，可选）

在 `main` 的“手稿本”里加“训练”页：

- **作品网格**：勾选“像我”；“用这张当参考”；
- **风格卡**：13 个滑杆 + 置信度条；可锁定某些维度；
- **A/B 对比**：并排两张，点“左边/右边更像”；10 轮一组的进度；
- **标签反馈**：太工整/太潦草/太斜/太细/太粗；
- **训练按钮**：`learn`，显示“样本 12 / 对比 9 / 置信度 0.72”；
- **导出**：风格 JSON、TTF（M2 之后）；
- **重置**：回到 basePreset。

对话内也能完成同样的闭环，UI 不是前置条件。

## 8. 里程碑

### S1 · 风格捕获（建议 1–2 个工作日）

- M1 历史记录（必须含 `style` + `strokesRef`）；
- `scribble_style` 的 `history` / `capture` / `list` / `get` / `activate`；
- `scribble_write` / `scribble_draw` 的 `profile` 参数；
- profile 存储、原子写、schema；
- 验收：从一张旧画捕获，新文字风格一致；同 seed 可复现。

### S2 · 反馈学习（建议 2–3 个工作日）

- `scribble_feedback`；
- 加权 μ/Σ、时间衰减、置信度；
- A/B 偏好模型、候选采样；
- 标签到维度的映射；
- 验收：5 次“太工整”后抖动明显增加；A/B 10 轮后偏好方向稳定。

### S3 · 字形适配（建议 3–5 个工作日，可选）

- 可打印样张生成；
- 图片分割/骨架化/对齐（优先用 Python 侧车，失败则退回手动 SVG）；
- 逐字 RBF 变形；
- 与 M2 的 TTF 导出打通；
- 验收：26 个大写字母样张能导出可辨识的 TTF；缺字有回退。

### S4 · UI（建议 2 个工作日，可选）

- 训练页、滑杆、A/B、置信度、导出/重置；
- 验收：不写代码的用户也能完成一次“捕获 → 反馈 → 再生成”。

---

## 9. 验收标准

1. 任意一张有矢量记录的旧画，`capture` 后新文字在 slant/weight/jitter 上肉眼一致；
2. 同一 profile + 同一 seed，输出 PNG 哈希一致；
3. `rating` 和 `tags` 能改变下一次生成（可量化：抖动/倾斜/粗细至少一项变化）；
4. A/B 10 轮后，偏好模型的排序与用户选择一致率 ≥ 70%（小样本自测）；
5. `confidence` 随样本数上升，UI/回执能看见；
6. `reset` 回到 basePreset；`export`/`import` 往返不丢字段；
7. 默认不联网；profile/history 全在本地；
8. S3 的 TTF 能被 `opentype.js` 读回，缺字回退到全局风格；
9. 不训练大模型、不引入原生 ML 依赖；纯 JS 推理；
10. 风格不会因一次负反馈塌缩：有正则、有探索、有重置。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 样本太少，风格过拟合 | 向 basePreset 收缩；置信度低时少改；一次反馈小步更新 |
| 用户说的“风格”其实是字形 | 明确区分；L0/L1 只改风格；要字形走 L2 样张 |
| A/B 反馈有噪声/偏见 | 成对比较 + 标签 + 可重置；不做“一次定终身” |
| 旧图只有 PNG，特征不准 | 优先矢量历史；图片特征降置信度；提示用户重新生成一张 |
| 手写照片骨架化质量差 | 打印样张 + 框内书写；失败可手动描摹；只承诺拉丁 |
| 风格塌缩/同质化 | 10% 探索；保留多个 profile；支持“分支风格” |
| 隐私 | 全本地；导出/删除；不遥测 |
| 字体许可证 | 用户自己的手写归用户；插件代码 MIT；不混入第三方字体数据 |

## 附录 · 关键公式

**加权画像**

```text
w_i = decay(age_i) × quality(rating_i) × similarity(θ_i, μ)
μ = Σ w_i θ_i / Σ w_i
Σ = λI + Σ w_i (θ_i - μ)(θ_i - μ)^T / Σ w_i
θ_new = clamp(μ + α L z, θ_min, θ_max),  LL^T = Σ
```

**偏好更新**

```text
p = σ(w · (φ(θ_a) - φ(θ_b)))
w ← w + η (y - p)(φ(θ_a) - φ(θ_b)) - λw
```

**候选打分**

```text
score(θ) = w · φ(θ) - β ||θ - μ||²
```

**置信度（示意）**

```text
confidence_d = 1 - exp(-n_d / 8)
```

`n_d` 是该维度被有效样本覆盖的次数；样本越多越接近 1。
